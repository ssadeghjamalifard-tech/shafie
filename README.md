# تقویم شیعه — ساخت APK

1. یه ریپوی جدید توی گیت‌هاب بساز و همه‌ی این فایل‌ها (با پوشه‌ی `.github`) رو توی شاخه‌ی `main` آپلود کن.
2. تب **Actions** → ورک‌فلو **Build APK** (خودش بعد از push اجرا می‌شه؛ یا Run workflow بزن).
3. بعد از تموم شدن، پایین صفحه‌ی همون اجرا از **Artifacts** فایل `tshia-apk` رو دانلود کن، unzip کن و `app-debug.apk` رو نصب کن.
4. اول که باز کردی اجازه‌ی اعلان رو بده. بعد ⚙️ تنظیمات ← «اعلان دائمی تاریخ».

برای عوض کردن صفحه‌ی برنامه فقط `www/index.html` رو جایگزین کن.
